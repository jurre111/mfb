Information

This bot is a highly simplified version of itsrespek's MADFUT Bot. I added this webpage for easier access. You can also interact with the bot via Discord. The bot only supports one command when installed to a user account which is /mf bottrade. It has the same functions as this webpage and you can find it in the section below.

Discord

To use the bot inside of Discord, you'll need to install the bot into your Discord account. Follow these steps to get it setup:

  1. Open this page. You might need to login in to Discord.
  2. Click "Add to My Apps"
  3. Scroll down, and click Authorize.

After that, you can use the command /mf bottrade anywhere in Discord. The bot will also send you a friendly greeting in your DM's, where you can then always find it. If you're not familiar with Discord's slash commands, you can find more information about it here. If you have any questions, you can find my Discord below.
