Information

To use the bot, you'll need to install the bot into your Discord account. Click the "Install bot" button above, click "Add to My Apps", scroll down, and finally click Authorize. After that, you can use the command /mf bottrade anywhere in Discord. If you have any questions, you can find my Discord below.

This bot is a highly simplified version of itsrespek's MADFUT Bot. It only supports one command when installed to a user account which is /mf bottrade. You can simply put in your MADFUT username and the amount of trades you want and it will send you an invite.
